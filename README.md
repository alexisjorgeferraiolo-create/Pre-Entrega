# Kisimayo — Tienda de Empanadas

Sitio web para la tienda Kisimayo, desarrollado como pre-entrega del proyecto Front-End.

## 📋 Descripción del proyecto
Sitio web con catálogo de productos, página de contacto y sección de carrito. Diseñado para verse correctamente en computadoras, tablets y celulares.

## 📁 Estructura del proyecto


## 🛠️ Tecnologías utilizadas
- **HTML5** → Estructura con etiquetas semánticas (`header`, `main`, `section`, `footer`, `nav`)
- **CSS3** → Estilos en archivo externo, sin estilos en línea
  - **Flexbox** → Posicionamiento y distribución de elementos
  - **Media Queries** → Diseño responsivo
  - **Font Awesome** → Íconos de redes sociales
  - **Google Fonts (Oswald)** → Tipografía
- **Formspree** → Recepción de mensajes del formulario de contacto

## ✅ Características
- ✅ Navegación entre las 3 páginas
- ✅ Diseño responsivo: se adapta a celulares, tablets y escritorio
- ✅ Imágenes que no se deforman
- ✅ Formulario de contacto funcional
- ✅ Etiquetas semánticas para mejor estructura
- ✅ Enlaces y rutas probadas
